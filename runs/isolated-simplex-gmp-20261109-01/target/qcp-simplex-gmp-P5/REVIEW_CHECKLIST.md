# P0 P1 主代理验收清单

本文件记录独立验收标准，不表示项目已通过验收。仅验收 P0、P1，不将未来单纯形接口声明视为已实现求解器。

## 来源与范围

- 冻结原项目 MiniGMP 文件及哈希，记录编译副本的转换和差异。
- 不修改原 QCP、旧原型、Yices、实验目录。
- 不静默使用系统 GMP；不导入外部 SMT 测试。
- 普通构建和 sanitizer 结果不标记为形式化验证。

## P0 数学和接口

- 原输入整数语义与内部有理数结果分开；错误不是数学 UNSAT。
- 只读输入、结果初始化和清理、失败后状态明确。
- 零变量、空约束、非法维度及环链表的契约明确。
- 换基符号独立核对：若 b=beta+a*e+sum(cj*xj)，则 e=-beta/a+b/a-sum(cj/a*xj)。其他行 k=gamma+d*e+sum(fj*xj) 替换后常数 gamma-d*beta/a，离基列 d/a，其余系数 fj-d*cj/a。
- 调整原基变量到边界，新基变量允许越界；边界归变量而不是基角色。
- 最小索引策略的终止前提不能冒充已证明；资源上限只导致 UNKNOWN。

## P1 内存和数值

- 检查每个底层分配/扩容路径，不仅外层对象分配。
- 失败不发布部分输出；部分初始化、临时对象和嵌套调用可清理。
- setjmp/longjmp 若采用，须检查修改后非 volatile 局部变量、嵌套边界、分配登记及旧输出所有权。
- 结构体复制不得造成 limb 浅拷贝、双重释放或交叉上下文所有权错误。
- 32 位 limb 与 LP64 long 区别明确；入口大数不能截断。
- int 长度加法、移位、绝对值和转换在发生未定义行为前受检查。
- 分数分母正，零为0/1，运算后规范化，除零独立诊断。
- 输出别名为左输入、右输入、两个输入相同均按契约处理。
- 预算与真实分配失败分别记录；超限不能误算为零。

## 独立测试

- 整数/分数算术与 Python int/Fraction 自编数据对照。
- 包含零、负数、整除与不整除、2^32/2^64邻域、低 limb 为零、多 limb 除法/GCD。
- 检查每个可公开算术入口及其支持的别名路径。
- 故障注入覆盖算术内部每个动态分配位置，检查输入及旧输出保持契约、存活分配恢复基线。
- 至少运行严格编译和适用的 ASan/UBSan；记录命令与实际输出。
- 核对基线哈希，确认原文件未改动。
