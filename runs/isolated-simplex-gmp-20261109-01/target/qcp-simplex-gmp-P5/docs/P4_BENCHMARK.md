# P4 当前版本预处理开关实测

2026-11-09。比较当前P4的disable_optimizations=15与0，不是冻结P3二进制性能比较。以下仅报告两份固定自编输入，本轮没有据此给普遍加速结论。

## 复现和计时边界

```sh
make clean
make all
make benchmark
```

默认重复30次，先做一次不计时warmup；偶数样本中位数取排序后中间两项平均。CLOCK_MONOTONIC纳秒计时只包sx_check/sx_check_qcp调用：含输入验证、前处理、建表/换基/全检、原行见证验证、内部清理及结果构造；排除输入整数构造、result_init/clear、进程启动和JSON输出。所有时间样本collect_matrix_stats=0，另有一次不计时的collect_matrix_stats=1采样提供矩阵数据。未绑核或控制系统负载，没有置信区间。

编译器：cc (Ubuntu 13.3.0-6ubuntu2~24.04.1) 13.3.0。普通参数：`-std=c11 -O2 -g`，新增代码另用`-Wall -Wextra -Werror -Wpedantic -Wconversion -Wshadow`。环境：Linux-6.18.33.2-microsoft-standard-WSL2-x86_64-with-glibc2.39。测量时二进制/静态库SHA256及每组mean/min/max、实际工作量见P4_BENCHMARK.json。

## 输入

dense：10行6变量，变量系数全部非零、常数均-1使整行GCD=1，零赋值已可行，0换基；无删行/列或归一化收益，默认走身份变换快路。sparse：18行12变量，其中12条常数真行，剩余6行把x0,x2,x4分别固定为1,2,3，统一含2^64正因子；其余9个变量未出现，3次换基。两者都返回Q FEASIBLE/Z SAT。

稠密例时间差很小，首次测量与重测的波动方向也不完全相同，不能据此声称加速。其默认路径仍多出首遍验证/GCD：分数导入786→857、包装层GCD730→740、分配18619→18815；身份快路使总峰值仍为19196 bytes，不代表额外工作消失。

稀疏例中，活动维数18×12→6×3，原变量系数非零数6保持不变，变量系数单元216→18；最后表按全部变量列计算的单元540→54，非零数均6。采样的表系数/常数最大limb长度3→1，控制流程均3次换基。实际分数导入8253→1294、包装层GCD1263→663、精确整除2526→1302。这里报告的时间/空间降低仅适用于该固定输入。

计数是当前实现包装层观测，非机器指令数；样例不覆盖所有退化、密度或系数分布，不能据少量样例推断一般复杂度。完整P2克隆和符号全检仍启用，下一阶段性能评估需更多分布和独立重复实验。
