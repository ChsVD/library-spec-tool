# P3 主代理验收报告

2026-11-09，P3 通过工程验收。GPT‑6.1 Sol（high）承担开发，主代理审查源码、编写独立用例并从源码复建。现在可以从公开 C 接口或命令行检查整数系数非严格不等式合取的有理数可行性。

## 公共行为

`sx_check` 接受带维度的整系数数组，`sx_check_qcp` 接受 NULL 终止的 QCP GMP FME 链表。两个入口使用同一修复循环。调用方保留输入所有权，成功结果拥有自己的见证或局部冲突记录，通过 `sx_result_clear` 清理。使用例子与预算约定见 [README](../README.md) 和 [P3 契约](P3_CONTRACT.md)。

| 验收输入 | 有理数结果 | 整数层结果 |
| --- | --- | --- |
| `2x=1` 拆为两行 | FEASIBLE，`x=1/2` | UNKNOWN，原因 FRACTIONAL |
| `1≤2x≤4` | FEASIBLE，`x=1/2` | UNKNOWN，该见证不能确认整数可行，实际另有整数解 `x=1` |
| `x+y=3` 和 `x−y=1`，各拆两行 | FEASIBLE，`(2,1)` | SAT |
| `x≥1` 和 `x≤0` | UNSAT，附冲突行与阻挡边界 | UNSAT |

FEASIBLE 逐行精确复核原始输入。在公共输入产生的冲突中，基表达式上界为零，求解器根据各非基变量的阻挡边界计算该表达式的最小可能值。严格大于零才发布 UNSAT。空间、时间、换基等资源耗尽有独立原因，Q/Z 均为 UNKNOWN。输入无效、真实分配失败、内部错误有单独的错误状态。

## 独立数学检查

在带显式盒边界的一至三维问题上，验收程序选取线性无关的紧约束，使用 Python `Fraction` 精确求交并代回全部约束。其依据是非空有界多面体存在顶点，低维可行集也适用。另有已知解的大系数等式、自由变量、行缩放、重排、重复行，以及加权相加直接得到 `1≤0` 的矛盾例。

两种公开入口各运行了同一组 76 个可行案例和 104 个不可行案例。每个可行见证均通过原行复核。每个不可行案例都把输出中的基表达式和阻挡表达式替换为原始行，逐项核对常数、各变量系数、边界方向及严格矛盾。这个独立检查是本测试集的验收手段。生产冲突记录的契约仍为局部算术证据。测试还检查输入内容和链接保持原状，以及在释放全部输入之后读取见证与冲突项。见 [测试程序](../tests/reviewer_p3.py)。

## 退出路径与审查修订

独立测试在可行、冲突两条路径的早期和最后检查点触发超时。已构造的候选输出得到清理。模拟时钟读取失败单独报内部错误。故障注入在最后一次分配触发时，两条路径均报告分配失败。预算等于峰值时求解成功，少一个字节时返回空间限制。换基数恰好够用时可以发布已完成的结果，只有仍需换基才报告次数耗尽。见 [退出路径测试](../tests/reviewer_p3_exit.c)。

审查中修复了 CLI 将嵌入 NUL 的非法数字截短并发布结果的问题。最大无符号时间预算改用经过时间比较，避免截止时刻加法溢出被误判为时钟故障。无法表示的尺寸统一报告 SIZE_OVERFLOW，独立测试覆盖零行且变量数为 `SIZE_MAX`。QCP 链表入口覆盖空链表、有效末节点、环和原节点所有权。

## 复现与边界

在开发目录运行 `python3 tests/reviewer_p3_acceptance.py`。脚本检查基线并依次进行 ASan/UBSan 与普通构建，最终保留普通构建产物。两种配置均通过 8,564 个 P3 全程逐点分配失败用例、184 个 CLI 精确案例及变换检查，并通过 P1/P2 回归和主代理的独立测试。61 个原始文件的哈希、基线提交及原 Git 状态与冻结记录一致。详细结果见 [验收日志](../build/reviewer_p3_acceptance.log)。

当前算法仍在每步换基克隆表并检查不变量。默认预算为 100,000 次换基、256 MiB 模块显式空间和 10 秒协作式时限。有限预算下的工程验收已完成。无预算循环的终止证明、完整整数求解、QCP 形式化验证和 P4 性能评估属于后续工作。
