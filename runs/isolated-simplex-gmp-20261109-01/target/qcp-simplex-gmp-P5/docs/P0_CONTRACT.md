## 接口、所有权、退出

SxProblem 行优先视图，每行 variables+1 个项目大整数，先常数项。调用方保持对象存活且只读；NULL 仅可在总元素数为0时使用。P2 将在解引用前检查 variables+1、rows*(variables+1) 和字节乘积溢出。裸 C 指针无法验证所有非法内存；合法初始化是前置条件。未来链表适配先独立检测环，再复制，永不释放调用方节点。

SxResult 由 init 建立空所有权；每次 check 前须清理旧结果；clear 可重复且回到空态。内部中途错误不发布数学结论。OOM/无效输入/内部错误与预算耗尽分离；预算耗尽 Q/Z UNKNOWN；有理数 FEASIBLE且全部原变量整数并复核为Z SAT；分数见证为Z UNKNOWN；Q UNSAT蕴含Z UNSAT。输出 UNKNOWN 无续算状态，只能以原输入重跑。当前 P1 不产生任何上述求解结果。

未来求解资源限制：表字节、单整数limb数、事务payload、换基次数和协作时间；上限耗尽不意味着不可行。无配置时也必须采用有限保守换基默认上限，建议100000；0表示默认而非无限。截止时间只在安全检查点检查，不抢占单次大整数运算。算术层当前没有时间限制。

## 换基等式

旧行 xb = beta + a*xe + sum(j!=e) aj*xj，a非零。
解出新行 xe = -beta/a + (1/a)*xb + sum(j!=e)(-aj/a)*xj。
另一行 xc = gamma + d*xe + sum(j!=e)cj*xj 更新为：
常数 gamma-d*beta/a；xb列 d/a；其他列 cj-d*aj/a。旧xb列在每行重写前为零。新基xe列为零。先算完整临时表并检查，最后交换角色与索引；失败销毁内部状态，不继续求解。

令旧越界xb的目标边界t，Delta=(t-value(xb))/a。
换基前旧非基xe变化Delta；旧基每个xc变化 coefficient(xc,xe)*Delta（包括xb变至t），旧xe变化Delta。
然后交换角色，新非基xb正好在界t，新基xe允许越界。等价的实现是先做换基，再将新非基xb设t并由新行重算所有基；P2调试须同时比较增量与完整重算。边界跟随变量编号，不跟随角色。

手算：s=1-x-y，s<=0，初值x=y=0、s=1。选x，a=-1、t=0，Delta=1，换基x=1-s-y，赋值x=1,s=y=0。另行z=2+3x-y更新为z=5-3s-4y，赋值z=5。
另一方向：s=2x+1，s>=3，x<=1/4；初始x=0,s=1。可选x增加，Delta=1，但新基x=1超原上界1/4，允许后续修复；不能以“一次调整不够”为由排除x。新行x=-1/2+s/2，新非基s=3满足下界。

合法方向：xb需增加时a>0且xe未达上界，或a<0且xe未达下界；xb需减少时a>0且xe未达下界，或a<0且xe未达上界。严格可移动判断，缺失界作无穷处理；a=0不选。非基满足边界是不变量。

没有方向时，所有非零列均被阻挡界固定在不能改善xb的方向。用该行系数符号取每列极值，得到xb的最大值仍小于下界，或最小值仍大于上界；这是充分不可行依据。P3需保留各阻挡边界来源，不声称它是完整原约束独立证书。

## 不变量和终止义务

表等价于初始等式；赋值满足表；基/非基分区及双向映射一致；非基在界内；边界属于固定变量；所有分数分母正且最简、零0/1。一次精确非零主元替换保持等式等价；上述赋值更新保持每行等式，新非基在界内，其余非基未变。因此局部保持性可直接代数推导，但尚未形式化。

固定最小变量编号选择不能在本项目直接引用标准形式Bland定理。完整终止论证仍须建立该有界修复变体的有限状态/词典序下降或适用反循环定理，明确退化、自由变量、上下双界、入基越界、相等边界条件，并证明与实际tie-breaking一致。有限个基不自动排除重复基和循环；有理数无限精度也不自动证明终止。目前没有已完成的无预算终止证明；有限换基与资源上限保证程序退出，其UNKNOWN不是数学结论。
