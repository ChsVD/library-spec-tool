# P2 主代理验收报告

2026-11-09，动态等式表、输入适配、边界管理和单步换基通过工程验收。GPT‑6.1 Sol（high）完成开发，主代理审查接口、实现与资源预算，编写独立用例并从源码复测。

## 数学行为

独立测试保存原始整数等式和指定的基，用 Python 标准库 Fraction 对基矩阵做高斯消元。每步重新推导整张表，包括每行常数、所有变量列、基与非基映射，以及每个变量的值。测试驱动在建表后立即释放源系数，检查结果的存储所有权。

71 组输入覆盖 204 个表状态和 133 次换基，含下界与上界修复、跨 64 位系数、零行、零变量，以及 12 个原变量和 20 行的输入。另用分数 1/3 移动非基变量，把表内借用的值作为下一次边界操作的输入，再用完整重算检查依赖行。整数输入和表内赋值均精确匹配。

## 内存与失败路径

独立预算测试先测得成功操作的显式分配峰值，再将预算设为该峰值和峰值减一字节。建表、换基都在等于峰值时成功。少一个字节时报告总空间限制，建表输出为空，换基保留原表的地址、内容和已有借用指针。还检查了 QCP 链表的有效尾节点、自环的拒绝和输入所有权。

审查中修正了建表系数复制首次失败后可能继续访问下一行的问题，统一了空表的限额校验，并用显式方向参数替代临时占位分数。最终版本的 4,369 个 P2 分配失败用例通过，测试结束时模块记录的存活字节回到初值。

## 工程取舍与下一阶段

每次修改先克隆一张候选表。候选表通过全量不变量和原等式等价性检查后才提交。这保证失败时旧表可继续使用，代价是两张表会同时占用内存，并增加每步运算量。总空间预算计入目标表、候选副本、长期分数和算术临时的显式分配。调用方输入、其他表及系统分配器内部开销在预算之外。

P2 的验收对象是单次表操作。公开可行性入口 `sx_check`、见证复核及整数与有理数结果解释属于 P3。本轮为工程验收，形式化验证和无预算终止证明仍待开展。
