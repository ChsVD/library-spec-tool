# QCP GMP 单纯形独立算术模块开发计划

2026-11-09 更新。P0–P5 交付范围已实现。`sx_check_qcp` 接收 FME 的 NULL 终止链表，与 `sx_check` 共用精确单纯形核心。P5 提供可校验的独立源码包、可编译的 QCP 链表示例、构建说明及验收记录。复现入口见 [README](README.md) 和 [P5 交付验收](docs/ACCEPTANCE_P5.md)。数学与工程依据分别见 [P2 表操作](docs/ACCEPTANCE_P2.md)、[P3 求解器](docs/ACCEPTANCE_P3.md) 和 [P4 验收与测量](docs/ACCEPTANCE_P4.md)。

采用“线性等式表＋变量上下界＋当前赋值”，通过换基修复基变量越界。不采用自由变量拆分和人工变量第一阶段目标。首版优先正确性、错误处理和可解释性，再用测量结果决定进一步优化。

## 1 目标和语义

输入为整数系数的非严格不等式合取：`c0 + Σ cj*xj <= 0`。原 QCP FME 语义面向整数变量：`Rocq/MonadLib/Examples/fme_rel.v` 定义 `LP_sol := list Z`。新核心检查其有理数放宽。

| 有理数结果 | 整数层解释 |
| --- | --- |
| UNSAT | 整数 UNSAT |
| FEASIBLE，原变量见证全部为整数，且精确复核成功 | 整数 SAT |
| FEASIBLE，原变量见证含分数 | 整数 UNKNOWN |
| 资源限制，未完成 | UNKNOWN |
| 无效输入、内部错误、分配失败 | 单独记录错误，不产生确定数学结论 |

例如 `2x=1` 拆成两条不等式后，核心应返回 FEASIBLE 和 `x=1/2`，整数层返回 UNKNOWN。分数见证不能证明不存在整数解，也不能让有理数核心改报 UNKNOWN。

输入没有关系类型字段。等式拆分、反向不等式转换由调用方或独立适配层处理。整数严格比较仅在取值条件成立时转换，且必须在有理数放宽前完成。大数取负和转换使用精确整数运算。实数严格比较和 `!=` 分支不属于本阶段。

## 3 问题表示和初始状态

每条约束引入表达式变量：`si = ci0 + Σ cij*xj`，设置 `si <= 0`。原变量保留为自由变量，表达式变量没有下界。

例如 `1-x-y<=0` 表示为 `s=1-x-y, s<=0`。初始 `x=y=0`，于是 `s=1`，等式成立但 s 越界。

原变量初始为非基变量、赋值零；表达式变量初始为基变量、赋值常数项。初始等式成立，非基变量满足边界，基变量允许越界。换基后边界跟随变量身份，不跟随其基或非基角色。

流程：只读输入 → 检查与预处理 → 建表和初始赋值 → 查找越界基变量 → 寻找可调整非基变量 → 换基并更新赋值 → 重复。没有越界项时恢复原变量并复核；不存在合法修复方向时构造冲突依据；资源不足时停止并清理。

## 5 动态状态和内存

首版为动态稠密表，表示 `xb = beta + Σ a_bj*xj`。保存基变量编号、非基编号、反向映射、分数系数、常数、赋值、边界和来源映射。无穷边界使用不存在标志，不能用巨大常数代替。

输入可以是 NULL 终止链表，内部不是链表。按输入规模申请数组，取消旧 8 变量、16 约束上限。计算变量数、行列乘积和字节数前检查溢出。扩容先申请成功再提交；所有部分初始化状态都有对应清理路径。

首版可线性扫描基变量查找越界。后续再考虑越界集合和稀疏行列索引，不把稀疏表示与核心正确性同时引入。

## 6 修复和换基

对于 `xb = beta + Σ aj*xj`，合法修复方向如下。

| xb 的需求 | aj 符号 | xj 的条件 |
| --- | --- | --- |
| 增大 | 正 | 未达上界或没有上界 |
| 增大 | 负 | 未达下界或没有下界 |
| 减小 | 正 | 未达下界或没有下界 |
| 减小 | 负 | 未达上界或没有上界 |

选择非零主元，交换基角色，把原越界基变量设到其违反的边界。新基变量可以越界，由后续循环修复。因此候选变量不必在原边界内一次完成全部调整。换基公式、符号和赋值更新次序必须先用手算例子检查。

若没有任何合法方向，该行与阻挡方向的边界形成矛盾。例如 `s=x+y, s>=3, x<=1, y<=1` 推出 `s<=2`，因此不可行。

首版使用固定编号的最小索引选择规则。P0 要为本算法明确终止性论证所需条件，不能机械套用标准形式单纯形的 Bland 定理，也不能把旧原型的换基上限说成终止性证明。达到资源上限只能 UNKNOWN。

## 7 算法不变量

1. 当前表与初始表达式等式系统等价。
2. 当前赋值满足全部表等式。
3. 基和非基形成分区，索引相互一致。
4. 非基变量满足各自边界，基变量可以暂时越界。
5. 换基只改变角色，不改变变量的边界。
6. 分母正、分数最简、零表示为 0/1。
7. FEASIBLE 必须经原约束复核；UNSAT 必须有充分冲突依据。

调试构建重新计算全部等式检查增量更新。生产路径保留必要安全检查和最终见证复核。

## 8 精确算术和首版优化

项目 MiniGMP 有外部分配等原语，且原接口假设分配成功。须补齐运行时并落实内部失败传播，不能只检查表的 malloc。底层失败设计通过测试后才集成求解循环。项目整数对象不能与系统 GMP 对象直接混用。

分数用两个项目大整数，运算先写临时结果，成功后提交。明确别名、初始化和释放责任，不依赖未经核对的底层原地操作。

首版加入交叉约分、分母 GCD、乘零加零快捷路径、主元列为零的行跳过消元。非基变量变化 delta 时，对受影响的基变量做 `value += coefficient*delta`，用完整重算作调试对照。

预处理仅删除常数真行、识别常数矛盾、除去整行共同正因子和移除未出现变量。必须保留有理数解集，不能静默加入整数取整强化。保留原始输入和映射以便复核。

稀疏存储、结构评分、小整数快速路径、增量查询和回溯不作为首版交付条件。记录非零比例、系数增长、分配和换基统计后再评估。优化不改变数学结果，但可能改变见证及资源耗尽情况。

## 9 输入输出契约

建议公共入口如下，具体类型布局在 P0 固定。

```c
void sx_result_init(SxResult *out);
void sx_check(const SxProblem *input,
              const SxLimits *limits,
              SxResult *out);
void sx_result_clear(SxResult *out);
```

SxProblem 是带维度的只读整数行视图。SxResult 包含 error、rational_status、integer_status、reason、原变量 witness 和 stats。有理数状态区分未运行、FEASIBLE、UNSAT、UNKNOWN；整数状态区分未判定、SAT、UNSAT、UNKNOWN。错误区分无效输入、分配失败、内部错误。禁止非零即成功判断。

调用方保留输入所有权。适配器复制系数，不改链表、不释放节点；要求调用方提供合法且长度正确的已初始化对象。裸指针不能可靠检测所有非法内存。动态链表适配不能沿用旧固定容量顺带拦截环的办法，需要独立检测环并记录无效输入。

out 须初始化，复用前清理。所有退出路径均能统一释放，释放后恢复初始化状态。内部状态返回前销毁；UNKNOWN 不支持续算，可用原输入重新调用。未复核候选值不能作为正式见证发布。错误发生时不得发布半完成的确定结论。

QCP FME 的 1 为检测到矛盾，0 为未检测到矛盾，不能机械对应整数 SAT。FME 修改输入并产生消元链表，本接口不提供相同副作用，不是原位替换。

## 10 资源限制

检查表空间、尺寸和字节数溢出、大整数长度及中间空间、换基次数和时间预算。可预测的越界须在操作前拦截。实际分配失败单独记录；配置预算耗尽返回 UNKNOWN。时间检查为协作式检查点，不保证立即打断单次大整数运算。

首版优先保证安全退出，不承诺失败后恢复原表续算。UNKNOWN 的可靠性与覆盖率分别评价。

## 12 自编测试计划

| 类别 | 示例与预期 |
| --- | --- |
| 空约束 | 有理数可行，原变量零赋值为整数见证 |
| 常数行 | -1<=0 为真；1<=0 为 UNSAT |
| 单变量冲突 | x>=1 且 x<=0 为 UNSAT |
| 分数见证 | 2x=1 拆两行，Q 可行，Z UNKNOWN |
| 多变量整数解 | x+y=3 且 x-y=1，唯一解 (2,1) |
| 多变量冲突 | x+y<=0 且 x,y>=1 为 UNSAT |
| 大系数 | 10^30*x=1，见证 1/10^30 |
| 超旧容量 | 9 个变量分别固定，共18行 |
| 方向覆盖 | 正负系数、上界和下界违反的四种调整 |
| 换基覆盖 | 新基变量继续越界、多次换基、退化和重复行 |
| 边界输入 | 零变量、无界变量、环链表和空系数指针 |
| 资源与释放 | 逐点分配失败、换基预算、数值预算、部分初始化清理 |

等式案例由测试构造器显式拆为两条不等式。每个 FEASIBLE 都精确代回全部原始行。对行重排、正整数缩放、重复行及增加未使用变量进行等价变换测试。用真实换基轨迹确认覆盖，不只依靠用例名称。

报告分别记录预期及数学依据、实际 Q/Z 状态、UNKNOWN 原因、内部错误、超时和释放检查。普通测试外运行适用的内存及未定义行为检查。

FME 只可独立对照，不能作为绝对裁判或生产回退。不一致时保存原输入并分析语义。旧 README 的测试数字未经本轮复跑，不纳入验收。性能比较必须固定输入、编译参数、数值表示和优化开关，说明计时是否含转换及见证复核。

## 13 后续证书和未支持能力

保留输入行、边界来源及行变换扩展位置。首版冲突信息说明哪一行及哪些边界阻挡方向，但不冒充可独立核验的完整原约束证书。后续跟踪线性组合，生成和检查矛盾证书；形式化规约和证明另行开展。

首版不支持完整整数推理、分支或割平面、完整 SMT、布尔搜索、理论协作、增量撤销、实数严格不等式、不等关系分支和 SMT 证明生成。
